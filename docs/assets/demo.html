FinLedgerApi

Double-entry micro-ledger — live API walkthrough

1  Create Accounts
bash
$ curl -s localhost:5000/accounts -X POST \
  -H 'Content-Type: application/json' \
  -d '{"name":"Cash","accountType":"Asset"}'

{
  "id": 1,
  "name": "Cash",
  "accountType": "Asset",
  "createdAt": "2026-06-08T08:39:15Z"
}
2  Post Transactions (Double-Entry)
bash
$ curl -s localhost:5000/transactions -X POST \
  -d '{"debitAccountId":1,"creditAccountId":2,
       "amount":1000,"description":"Initial deposit",
       "transactionType":"Credit"}'

→ Creates entry on Account 1 (debit: 1000)
→ Creates entry on Account 2 (credit: 1000)
→ Both sides balanced. Ledger integrity maintained.
3  View Account Statement (Running Balance)
bash
$ curl -s localhost:5000/accounts/1/statement

{
  "id": 1,
  "name": "Cash",
  "entries": [
    { "amount": 1000, "type": "Credit", "runningBalance": 1000 },
    { "amount": 250,  "type": "Debit",  "runningBalance": 750 }
  ]
}
4  Net Balances Across Accounts
bash
$ curl -s localhost:5000/accounts

[
  { "id": 1, "name": "Cash",     "accountType": "Asset",    "netBalance": 750 },
  { "id": 2, "name": "Revenue",  "accountType": "Revenue",  "netBalance": 0 },
  { "id": 3, "name": "Savings",  "accountType": "Asset",    "netBalance": 0 }
]
Validation
bash
$ curl -s localhost:5000/transactions -X POST \
  -d '{"debitAccountId":999,"creditAccountId":2,"amount":100}'

"Account 999 not found."

$ curl -s localhost:5000/transactions -X POST \
  -d '{"debitAccountId":1,"creditAccountId":1,"amount":100}'

"Debit and credit accounts must be different."
